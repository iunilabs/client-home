# Contenido de las páginas comerciales

Contraste: 3 de octubre de 2026. El texto se ha reescrito para la nueva web,
sin copiar íntegramente la web corporativa ni inventar cifras, testimonios o
resultados. IA y automatización describe propuestas de servicio, no casos
de clientes documentados.

- [Quiénes somos](https://www.puntoes.es/quienes-somos/): misión, 1999, ICAP
  (2003), Tecfortres (2010), equipo humano y atención personalizada.
- [Consultoría](https://www.puntoes.es/consultoria/): negocio, banca y nuevas
  tecnologías; responsabilidad, compromiso, seguimiento; diagnóstico,
  planificación y aplicación. Outsourcing también forma parte del alcance
  comercial indicado por el cliente.
- [Formación](https://www.puntoes.es/formacion/): desarrollo, datos,
  Agile/Scrum, Office/VBA, gestión/dirección de proyectos. Los programas
  resumen esas áreas y sus catálogos, sin afirmar fechas, precios, horas ni
  certificaciones vigentes. Las consultas sirven para concretar el programa.
- [Clientes](https://www.puntoes.es/clientes/): nombres y logos ya presentes
  en el proyecto, procedentes de la web corporativa. No se afirma que haya
  contratos actuales ni proyectos de IA con esas organizaciones.
- [BBVA Customer Solutions](https://www.puntoes.es/bbva-customer-solutions/):
  publicación de 2017 e inicio de colaboración en 2009, ambos explicitados.
- [Contacto](https://www.puntoes.es/contacto/): 91 556 09 39,
  puntoes@puntoes.es, formulario público 119. Formación usa
  formacion@puntoes.es, publicado en sus páginas de cursos.
- Privacidad: se conserva el enlace al PDF oficial; no se inventa una política.

Las seis entradas HTML se compilan como páginas independientes para permitir
acceso directo en GitHub Pages. `templates.js` comparte header y footer en
build y desarrollo. `main.js` solo carga navegación, filtros y formulario;
ninguna página interior importa Three.js, Lenis ni modelos 3D.
